# AksharSetu - Bridging People Through Knowledge

Welcome to the internal documentation for **AksharSetu**, a modern production-grade platform for book resale and donations.

## 📚 Project Documentation

This directory contains the foundational planning, product definitions, and architectural blueprints for the AksharSetu project.

1. **[Features and Ideas](./01-features-and-ideas.md)**: Initial brainstorming on core value propositions and gamification.
2. **[Technology Stack](./02-tech-stack.md)**: Outlines the chosen tools and frameworks.
3. **[System Architecture](./03-architecture.md)**: Early high-level system design and data flow.
4. **[Future Scalability](./04-scalability.md)**: Ideas for scaling the platform long-term.
5. **[Product and MVP](./05-product-and-mvp.md)**: Defines the core product, target users, MVP scope, and search capabilities.
6. **[Data Model and Lifecycle](./06-data-model-and-lifecycle.md)**: Details the critical separation of Books vs. Listings, state management, and double-selling prevention.
7. **[Trust, Safety, and Donations](./07-trust-safety-and-donations.md)**: Outlines moderation, the structured book condition system, and transparent donation tracking.
8. **[Development Roadmap](./08-development-roadmap.md)**: Explains the modular monolith approach, structured project layout, vertical slicing, and API design.

## 🚀 Getting Started
The frontend application scaffolding is located in the `/web` directory (Next.js + Tailwind CSS).

The backend architecture is planned as a modular monolith relying on PostgreSQL for robust relational data mapping.
